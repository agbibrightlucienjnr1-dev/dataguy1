Documentation / Payment / Initiate Payment
Initiate Payment
POST
https://api.moolre.com/open/transact/payment

This endpoint allows you to initiate a payment by sending a USSD payment request to a payer's/customer's phone number for approval.



verified_user
Public vs. Private API Keys
expand_more
Public API Key (X-API-PUBKEY)
Recommended for Collections. Safe for use in client-side code (JavaScript Inline, Mobile Apps). Valid for 5 years. Does not expire when your password changes.

Private API Key (X-API-KEY)
For Server-Side Only. Required for Payouts (Transfers) and sensitive Account Management. Must NEVER be exposed in frontend code. Expires every time you generate a new key or change your password.

* Both keys work for Payment initiation, but using the Public Key is the security best practice for frontend integrations.

Payment Lifecycle
expand_more
send
Step 1
Initial Request
Pass all required parameters. To prevent fraud, a One-Time Password (OTP) is sent to the payer (customer) via SMS.

sms
Step 2
Collect OTP
The Customer must provide the code to you via your User Interface to prove they own the number being used to make the payment.

verified_user
Step 3
Verify OTP
Pass all required parameters again and include the OTP in the otpcode parameter.

check_circle
Step 4
Verification Response
If verification is successful, a success response is returned. If unsuccessful, the request will fail.

payments
Step 5
Trigger Payment Prompt
Pass all required parameters to this endpoint again (without OTP) to initiate the actual payment request.

smartphone
Step 6
Customer Approval
The Customer receives a prompt on their screen and enters their Mobile Money PIN to approve the payment.

account_balance_wallet
Step 7
Instant Settlement
Upon approval, the Customer is debited and your Moolre wallet/account is credited instantly.

Shell request

curl --request POST \
     --url 'https://api.moolre.com/open/transact/payment' \
     --header 'X-API-USER: Your Username' \
     --header 'X-API-PUBKEY: YOUR_PUBLIC_KEY' \
     --header 'Content-Type: application/json' \
     --data '{

  "channel": "13",
  "currency": "GHS",
  "payer": "",
  "amount": "",
  "externalref": "",

Payment Status
POST
https://api.moolre.com/open/transact/status

This endpoint allows you to check the final status of a transaction. It is the same as the Transfer Status endpoint. Please refer to the Transfer Status endpoint for details.

lightbulb
Public API Key Usage
Public API Key can also be used to check the status of a transaction.

dangerous
Do not Assume Transfer Failure
Never assume a transfer has failed unless the transfer response or status check response txstatus indicates failure with a value of 2.

Documentation / Payment / Payment Webhook
Payment Webhook
POST
{{WEBHOOK_CALLBACK_URL}}

You provide your callback url when creating your wallet, activating API or generating a payment link. When payments are received a callback is sent to your callback URL.

Field Description
Field	Description	Format
txstatus	Represents the transaction status: 1 (Successful), 0 (Pending), 2 (Failed).	Integer
payer	The number to which the prompt was sent and from which the funds were debited.	String
terminalid	The terminal ID of a wallet that received an incoming transaction.	String
accountnumber	The account number of a wallet that received an incoming transaction.	String
name	A name or unique ID provided during creation of a terminal ID for Merchant reference.	String
amount	The amount specified for the transaction.	Double
value	The actual amount credited/debited, minus any applicable fees.	Double
transactionid	A unique transaction ID generated by Moolre.	Integer
externalref	A unique ID generated by the integrating party to identify each transaction.	String
thirdpartyref	The transaction ID of the receiving or sending institution.	String
secret	A unique string to verify that the callback is from Moolre.	String
ts	The timestamp of the transaction (GMT).	String
